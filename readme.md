# वस्त्र forever

### Timeless Style. Everyday Elegance.

A modern, minimalist fashion e-commerce platform designed to deliver a smooth and elegant online shopping experience.

**VASTRA forever** is a fashion e-commerce project built with a clean white aesthetic, modern UI components, and a scalable architecture. The project aims to provide a complete shopping experience for customers, along with powerful product and order management capabilities for administrators.

---

## Project Overview

VASTRA forever is being developed as a full-stack e-commerce application inspired by modern fashion retail platforms.

The platform is planned to include product discovery, category-based browsing, shopping cart management, secure authentication, order processing, online payments, and an admin dashboard.

## Brand Identity

- **Brand:** VASTRA forever
- **Industry:** Fashion & E-commerce
- **Design:** Minimalist, elegant, and modern
- **Primary Theme:** White and black
- **Typography:** Indian-inspired Devanagari branding paired with modern English typography

## Getting Started

Follow these instructions to run the frontend locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git
- Visual Studio Code

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-GITHUB-USERNAME/vastra-forever.git
```

### 2. Navigate to the Project

```bash
cd vastra-forever
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```
